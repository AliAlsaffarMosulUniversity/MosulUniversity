# أنشطة جامعة الموصل

تطبيق Android أصلي بـ Kotlin وJetpack Compose لعرض الأنشطة المنشورة في مصادر جامعة الموصل الرسمية، مع التصفية حسب الكلية وشهر **النشر**. لا يحتوي التطبيق على بيانات تجريبية أو أحداث منشأة يدوياً، ويفتح كل بطاقة رابط المنشور الأصلي.

## البناء والتشغيل

- افتح المشروع في Android Studio حديث مع JDK 17 وAndroid SDK Platform 36، ثم اسمح بمزامنة Gradle.
- شغّل إعداد `app` على جهاز أو محاكي Android 8.0 (API 26) أو أحدث.
- لتشغيل الاختبارات من سطر الأوامر بعد توفر JDK 17 وبيئة Android SDK: `.\gradlew.bat testDebugUnitTest`.
- يستخدم المشروع Android Gradle Plugin 8.7.3؛ البناء على SDK 36 ينجح لكنه يصدر تحذيراً لأن هذا الإصدار اختُبر حتى SDK 35.

## مصادر البيانات وحدودها

- قائمة الكليات تُقرأ من صفحة [كليات الجامعة](https://uomosul.edu.iq/كليات_الجامعة/) الرسمية (معرّف صفحة WordPress: `72353`) وتُستخرج أسماء الكليات وروابط مواقعها من بطاقات الصفحة.
- الأنشطة الصريحة تُقرأ من تصنيف WordPress الرسمي «نشاطات الكليات» (معرّفه `33`؛ كان يعرض 27 منشوراً عند فحص المصدر في 1 تشرين الأول 2026).
- لأن أحدث منشورات ذلك التصنيف التي أعادها الموقع كانت من 2019–2022، يضم التطبيق أيضاً أخبار الجامعة (التصنيف `32`) فقط عندما يذكر نص المنشور كلية مدرجة ونشاطاً صريحاً مثل ندوة أو ورشة أو مؤتمر. أحدث منشور في عينة هذا التصنيف كان بتاريخ 29 كانون الأول 2025 عند الفحص في 1 تشرين الأول 2026. لا تُعرض الأخبار العامة بهذه الصفة.
- يتوفر RSS عام (`/feed/`) لكنه أعاد عنصراً واحداً عند الفحص؛ لذلك يعتمد التطبيق على REST API العام لـWordPress، مع ترقيم صفحات نتائج الأخبار والأنشطة.
- هذه واجهة تجميع لمحتوى موقع الجامعة الرئيسي وليست مصدراً موحداً لمنشورات المواقع المنفصلة لكل كلية؛ أي نشاط غير منشور على الموقع الرئيسي أو لا يذكر الكلية/النشاط بوضوح قد لا يظهر. زر «تحميل منشورات أقدم» يتابع صفحات REST المتاحة.
- التاريخ الظاهر هو تاريخ نشر WordPress، وليس بالضرورة تاريخ انعقاد النشاط. تُعرض حالة فارغة أو تحذيرات مصدر واضحة عند عدم توفر البيانات أو عدم العثور على تطابق؛ ولا يُستبدل المحتوى الرسمي بعناصر وهمية.
